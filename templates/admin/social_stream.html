Churchgate Facebook Page (auto import)

  1. On Facebook, create a Page for your church (or use existing).
  2. Upload / publish videos as Public on that Page.
  3. In Meta for Developers, create an app → get a Page access token with pages_read_engagement / pages video read permissions.
  4. Paste Page ID + token below → Save → Sync videos from Page.

Sync imports new public Page videos into the member Social Watch feed. Duplicates are skipped. You can still paste individual links below.

Manual add: public live channels, movies and news / YouTube (including Live). Members: vertical feed, autoplay muted on scroll, sound toggle.
